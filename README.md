# FIELDOS

A product-concept website for **FIELDOS**, an agricultural intelligence platform.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run lint
npm run build
```

## Brand

Product name, tagline, contact email, and social placeholders live in `src/config/brand.ts`.

## Notes

Product UI on the site is conceptual. Early-access submissions currently POST to `/api/early-access` and are logged only.
